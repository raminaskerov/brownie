Brownie Windows development build

1. Extract the entire ZIP.
2. Make sure Google Chrome is installed.
3. Double-click Brownie.exe.
4. Brownie opens its controls in your normal browser.
5. Add the model keys supplied for the test under "Model keys".
6. Use "Quit Brownie" before deleting or replacing this build.

This is an unsigned development build. Windows may show a SmartScreen warning.
Keep the _internal folder beside Brownie.exe.
